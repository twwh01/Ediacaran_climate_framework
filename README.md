# Supplementary code for Ediacaran coupling of climate and biosphere dynamics
This is the supplementary code for a manuscript that is now published in GSA Bulletin: [https://doi.org/10.1130/B39047.1](https://doi.org/10.1130/B39047.1). 

The preprint of the originally submitted version is available on EarthArXiv: [https://eartharxiv.org/repository/view/8749/](https://eartharxiv.org/repository/view/8749/).

# Set up instructions
If you are new to programming with R, first download and install RStudio. 

The code here is bundled as an R project which you can open and work with in RStudio. 

For this to work seemlessly, keep the directory structure as it is here. 

Running ``dependencies.R`` will install all of the packages needed for this project. 

The scripts in directory "scripts" are labelled by the analysis and figures they produce.
